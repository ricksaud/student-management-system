# Student Management System

A full-stack web application developed using Spring Boot for managing students, modules, and grades.

## Features
- User authentication (Spring Security)
- Student, Module, and Grade management (CRUD)
- MySQL database integration
- Dashboard with charts and analytics
- Search functionality
- Data linked to authenticated user

## Technologies Used
- Java
- Spring Boot
- Spring Security
- MySQL
- Thymeleaf
- Chart.js

## How to Run
1. Clone the repository:
   git clone https://github.com/ricksaud/student-management-system.git

2. Open in IntelliJ

3. Configure `application.properties`:
   - database URL
   - username
   - password

4. Run the project
